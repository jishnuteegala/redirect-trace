# Issue tracker

Issues for this repo live in **GitHub Issues** (https://github.com/jishnuteegala/redirect-trace/issues), managed via the `gh` CLI.

Chosen at factory setup (2026-08-01): established GitHub repo, long-running multi-session factory effort, native `Closes #N` clearing and blocking relationships wanted.

PRs as a request surface: off.

Triage labels: defaults (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).

Domain docs: single-context - `CONTEXT.md` at repo root, ADRs under `docs/adr/`.
